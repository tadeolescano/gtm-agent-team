# Example: a draft stays a draft

> Fictional example. Company and people are invented.

## Input

> Write a follow-up to the Globex Logistics ops lead about the pilot.

## Router output

The request names the content but not an instruction to send, so the router returns a draft:

```
To:      Ops lead, Globex Logistics (address from the original thread)
Subject: Pilot next steps

Hi Dana,

Following up on Tuesday's call. The two-week pilot can start on Monday
with the three depots you mentioned. I need one thing from your side:
read-only access to last month's delivery exceptions export.

Does Monday work?
```

> Draft above. Say "send it" and I'll send this one message to Dana.

## Why

Writing is not sending. Approval must name the message and the recipient, and it covers one send.
