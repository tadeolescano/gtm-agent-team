# Example: refusing to invent

> Fictional example.

## Input

> How much is Globex spending on ads per month?

## Output

> Not public. The ad libraries show 22 active ads `[FACT]` but not spend; spend is only disclosed for political ads.
> A range is possible only with a stated method, e.g. `[ESTIMATE]` 8k to 25k/month from ad count x typical run length x a CPM range, which is weak. I'd treat it as directional only.
